Deskripsi Eksperimen : Eksperimen ini dilakukan untuk menerapkan metode Machine Learning dalam mengklasifikasikan tumor payudara berdasarkan karakteristik sel yang terdapat pada Breast Cancer Wisconsin Dataset. Dataset yang digunakan berasal dari library Scikit-learn dan terdiri atas 569 sampel dengan 30 fitur numerik serta dua kelas target, yaitu malignant (ganas) dan benign (jinak). Sebelum dilakukan pemodelan, data diperiksa terlebih dahulu untuk mengetahui struktur dataset, distribusi kelas, dan keberadaan data kosong (missing values). Hasil pemeriksaan menunjukkan bahwa tidak terdapat data kosong pada dataset.

Pada tahap pemodelan, dilakukan perbandingan dua algoritma klasifikasi, yaitu Logistic Regression dan Random Forest. Dataset dibagi menjadi 70% data training dan 30% data testing dengan menggunakan teknik stratifikasi agar proporsi kedua kelas tetap terjaga. Kedua algoritma kemudian dilatih menggunakan data training dan dievaluasi menggunakan data testing. Selain itu, eksperimen dilanjutkan dengan membangun model Logistic Regression menggunakan pembagian data 80% training dan 20% testing. Model ini menggunakan StandardScaler untuk menyamakan skala fitur sebelum proses klasifikasi. Evaluasi dilakukan menggunakan accuracy, precision, recall, F1-score, ROC-AUC, dan confusion matrix untuk mengetahui kemampuan model dalam mengklasifikasikan tumor berdasarkan karakteristik yang tersedia.

Hail Evaluasi : Berdasarkan hasil pengujian dengan pembagian data 70% training dan 30% testing, algoritma Logistic Regression memperoleh akurasi sebesar 98,83%, sedangkan Random Forest memperoleh akurasi sebesar 93,57%. Hasil classification report menunjukkan bahwa Logistic Regression memiliki nilai precision, recall, dan F1-score yang lebih tinggi dibandingkan Random Forest pada kedua kelas. Dengan demikian, Logistic Regression menunjukkan performa klasifikasi yang lebih baik pada pengujian perbandingan kedua algoritma.

Pada pengujian lanjutan menggunakan pembagian data 80% training dan 20% testing, model Logistic Regression memperoleh akurasi sebesar 98,25% dengan nilai precision, recall, dan F1-score sebesar 0,98 pada kelas malignant serta 0,99 pada kelas benign. Nilai ROC-AUC yang diperoleh sebesar 0,9954, menunjukkan kemampuan model yang sangat baik dalam membedakan kedua kelas. Berdasarkan confusion matrix, model berhasil mengklasifikasikan 41 sampel malignant dan 71 sampel benign dengan benar, sedangkan terdapat masing-masing satu sampel dari kedua kelas yang salah diklasifikasikan.

Kesimpulan : Berdasarkan eksperimen yang telah dilakukan, metode Machine Learning dapat digunakan untuk membantu proses klasifikasi tumor payudara berdasarkan karakteristik data yang tersedia. Dari perbandingan dua algoritma, Logistic Regression menghasilkan performa yang lebih baik dibandingkan Random Forest, dengan akurasi masing-masing sebesar 98,83% dan 93,57%. Pada pengujian lanjutan, Logistic Regression juga menunjukkan hasil yang baik dengan akurasi 98,25% dan ROC-AUC sebesar 0,9954. Hasil tersebut menunjukkan bahwa Logistic Regression memiliki kemampuan klasifikasi yang sangat baik pada dataset yang digunakan. Namun, model ini masih perlu diuji menggunakan data independen dan validasi lebih lanjut sebelum dapat dipertimbangkan untuk penggunaan dalam konteks medis. Eksperimen ini merupakan penerapan pembelajaran Machine Learning dan bukan pengganti diagnosis medis.
