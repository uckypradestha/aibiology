Deskripsi eksperimen: Eksperimen ini dilakukan untuk membandingkan performa dua algoritma klasifikasi, yaitu Logistic Regression dan Random Forest, dalam mengklasifikasikan kanker payudara berdasarkan dataset Breast Cancer Wisconsin dari Scikit-learn. Dataset yang digunakan terdiri dari 569 data dengan 30 fitur numerik yang menggambarkan karakteristik tumor, serta dua kategori target, yaitu malignant (tumor ganas) dan benign (tumor jinak). Sebelum dilakukan pemodelan, data diperiksa terlebih dahulu untuk mengetahui kelengkapan dan karakteristiknya. Hasil pemeriksaan menunjukkan bahwa tidak terdapat nilai yang hilang (missing values) pada dataset. Selanjutnya, dataset dibagi menjadi 70% data training sebanyak 398 data dan 30% data testing sebanyak 171 data menggunakan metode train_test_split dengan parameter stratify=y dan random_state=42 agar proporsi kelas tetap terjaga. Pada algoritma Logistic Regression digunakan proses standardisasi fitur menggunakan StandardScaler dengan jumlah iterasi maksimum 1000. Sementara itu, algoritma Random Forest menggunakan 100 pohon keputusan (n_estimators=100). Kedua algoritma kemudian dilatih menggunakan data training dan diuji menggunakan data testing untuk menghasilkan prediksi klasifikasi. Hasil prediksi tersebut selanjutnya dievaluasi menggunakan beberapa metrik, yaitu accuracy, precision, recall, F1-score, dan ROC-AUC untuk mengetahui serta membandingkan kemampuan masing-masing algoritma dalam mengklasifikasikan tumor ganas dan jinak.

Hasil evaluasi: Berdasarkan hasil eksperimen, algoritma Logistic Regression menunjukkan performa klasifikasi yang lebih baik dibandingkan Random Forest. Logistic Regression memperoleh nilai accuracy sebesar 98,83%, sedangkan Random Forest memperoleh nilai sebesar 93,57%. Pada evaluasi precision, Logistic Regression mendapatkan nilai 98,83%, sementara Random Forest memperoleh 93,55%. Selanjutnya, nilai recall Logistic Regression mencapai 98,83%, sedangkan Random Forest sebesar 93,57%. Pada metrik F1-score, Logistic Regression memperoleh 98,83% dan Random Forest memperoleh 93,56%. Hasil tersebut menunjukkan bahwa Logistic Regression memiliki performa yang lebih unggul dan konsisten berdasarkan seluruh metrik evaluasi yang digunakan. Jika dilihat berdasarkan classification report, Logistic Regression memperoleh recall sebesar 0,98 pada kelas malignant dan 0,99 pada kelas benign. Sementara itu, Random Forest memperoleh recall sebesar 0,91 pada kelas malignant dan 0,95 pada kelas benign. Perbedaan ini menunjukkan bahwa Logistic Regression memiliki kemampuan lebih baik dalam mengenali data tumor ganas pada pengujian tersebut. Selain itu, hasil pengujian ROC-AUC menunjukkan bahwa Logistic Regression memperoleh nilai 0,9981, sedangkan Random Forest memperoleh 0,9913. Kedua nilai tersebut menunjukkan kemampuan diskriminasi kelas yang sangat baik, meskipun Logistic Regression tetap memperoleh nilai lebih tinggi. Secara keseluruhan, hasil evaluasi memperlihatkan bahwa Logistic Regression memberikan hasil klasifikasi yang lebih optimal dibandingkan Random Forest pada dataset yang digunakan.

Kesimpulan: Berdasarkan eksperimen dan hasil evaluasi yang telah dilakukan, dapat disimpulkan bahwa algoritma Logistic Regression merupakan algoritma yang memberikan performa klasifikasi lebih baik dibandingkan Random Forest dalam mengidentifikasi tumor ganas dan jinak pada dataset Breast Cancer Wisconsin. Keunggulan tersebut dibuktikan melalui nilai accuracy sebesar 98,83%, precision sebesar 98,83%, recall sebesar 98,83%, F1-score sebesar 98,83%, dan ROC-AUC sebesar 0,9981. Sementara itu, Random Forest memperoleh accuracy sebesar 93,57%, precision sebesar 93,55%, recall sebesar 93,57%, F1-score sebesar 93,56%, dan ROC-AUC sebesar 0,9913. Penggunaan StandardScaler pada Logistic Regression juga membantu menyamakan skala fitur sehingga mendukung proses pembelajaran model. Dalam konteks klasifikasi kanker, evaluasi tidak cukup hanya menggunakan akurasi karena metrik tersebut tidak menunjukkan secara spesifik kesalahan prediksi pada masing-masing kelas. Kesalahan False Negative, yaitu ketika tumor ganas diprediksi sebagai tumor jinak, perlu mendapatkan perhatian khusus karena dapat menyebabkan kasus kanker tidak terdeteksi. Oleh karena itu, penggunaan precision, recall, F1-score, ROC-AUC, dan confusion matrix diperlukan untuk memberikan gambaran performa model yang lebih menyeluruh.
