Deskripsi eksperimen : 
Eksperimen ini dilakukan untuk membandingkan performa dua algoritma klasifikasi machine learning, yaitu Logistic Regression dan Random Forest, menggunakan dataset Breast Cancer Wisconsin. Dataset ini terdiri dari 569 data dengan 30 fitur yang menggambarkan karakteristik tumor payudara. Klasifikasi dilakukan untuk membedakan dua kategori tumor, yaitu malignant (ganas) dan benign (jinak). Sebelum proses pemodelan dilakukan, dataset diperiksa terlebih dahulu untuk mengetahui informasi data, distribusi kelas, dan keberadaan nilai kosong (missing values). Berdasarkan pemeriksaan, tidak ditemukan nilai kosong pada dataset sehingga seluruh data dapat digunakan dalam proses eksperimen. Selanjutnya, dataset dibagi menjadi 70% data training sebanyak 398 data dan 30% data testing sebanyak 171 data menggunakan train_test_split dengan parameter random_state=42 dan stratify=y. Setelah pembagian data, dilakukan proses pelatihan menggunakan dua algoritma. Pada Logistic Regression digunakan StandardScaler untuk melakukan standardisasi fitur dan parameter max_iter=1000, sedangkan Random Forest menggunakan parameter n_estimators=100 dengan random_state=42. Kedua model kemudian digunakan untuk memprediksi data testing dan hasilnya dibandingkan menggunakan beberapa metrik evaluasi, yaitu accuracy, precision, recall, F1-Score, dan ROC-AUC.

Hasil Evaluasi : 
Berdasarkan hasil pengujian terhadap 171 data testing, algoritma Logistic Regression memperoleh nilai accuracy sebesar 98,83%, sedangkan Random Forest memperoleh nilai accuracy sebesar 93,57%. Pada metrik precision, Logistic Regression memperoleh nilai 98,83% dan Random Forest sebesar 93,55%. Selanjutnya, nilai recall Logistic Regression mencapai 98,83%, sedangkan Random Forest memperoleh 93,57%. Pada metrik F1-Score, Logistic Regression mendapatkan nilai 98,83%, sementara Random Forest memperoleh 93,56%. Hasil evaluasi ROC-AUC juga menunjukkan bahwa Logistic Regression memiliki nilai sebesar 99,81%, lebih tinggi dibandingkan Random Forest yang memperoleh 99,13%. Berdasarkan keseluruhan hasil tersebut, Logistic Regression menunjukkan performa klasifikasi yang lebih baik karena memperoleh nilai evaluasi lebih tinggi pada seluruh metrik yang digunakan. Model Logistic Regression juga berhasil mengklasifikasikan sekitar 169 dari 171 data pengujian dengan benar, sedangkan Random Forest berhasil mengklasifikasikan sekitar 160 data dengan benar. Hal ini menunjukkan bahwa Logistic Regression memiliki kemampuan prediksi yang lebih tinggi pada dataset yang digunakan dalam eksperimen ini.

Sementara itu, Random Forest merupakan algoritma klasifikasi yang menggunakan gabungan beberapa pohon keputusan (Decision Tree) untuk menghasilkan prediksi.
